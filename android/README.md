# Star Quarry (Android)

A 3D idle space-mining game. No ads, no in-app purchases, no premium currency.

## Build the APK
1. Install Android Studio (free): https://developer.android.com/studio
2. From the repository root, run `python3 -I src/build.py` first: it writes the game into `app/src/main/assets/index.html`.
3. File > Open and pick this `android` folder. Let Gradle sync (it downloads Gradle 8.7 and the Android plugin the first time).
4. Phone: Settings > About phone > tap "Build number" 7 times, then enable USB debugging in Developer options.
5. Plug in the phone and press Run, or use Build > Build App Bundle(s) / APK(s) > Build APK(s).
   The APK lands in `app/build/outputs/apk/`.

## How it's put together
- `app/src/main/assets/index.html` (generated by `src/build.py`, not stored in the repository) is the entire game: Three.js r128 (inlined, works offline), the 3D scene, and the economy.
- `MainActivity.kt` hosts it full-screen in a WebView. Saves live in WebView localStorage.
- Release builds are signed with the debug key so they install directly. Set up your own signing key before uploading to the Play Store.

## Tuning
All balance numbers sit at the top of the script in `src/game.html` (the source; never edit the built copy): `ORES` (values), `PLANETS` (unlock costs, ore mixes),
`RESEARCH` (costs and multipliers), and the upgrade curves in `GROW`.
