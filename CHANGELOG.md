# Star Quarry change log

Every version of Star Quarry, newest first. Each release starts with the summary players see in the game
(Warp tab, What's changed), then lists every version that went into it. The commits on `main` and `dev` hold
the code-level detail. Generated by `src/build.py` from `src/releases.json` and `src/changelog.json`: never
edit by hand.
